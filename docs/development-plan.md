# 开发方案与当前边界

Agent Handoff 面向同一台 Mac、同一用户下的本地编码会话。接收端按需通过中转站查找和读取选中的来源会话，源客户端可以已退出。发送方也可以先保存版本并创建指派，接收方稍后从收件箱领取。两条路径复用同一套工作树校验和目标发布逻辑。

## 已实现

| 阶段 | 交付能力 |
|---|---|
| M0 | 用实际客户端区分会话可发现、能打开以及在正确工作树继续执行。 |
| M1–M2 | 提供 Rust CLI 和 stdio MCP，共享 SQLite 状态。支持预览、幂等发布及历史和笔记的有界回读。 |
| M3–M4 | Codex、Claude Desktop Code、DeepSeek Harness 两两转换。从接收端查询候选、选择来源并拉取。查询支持项目过滤、分页及 ID、标题、可见正文子串匹配。 |
| M5 | 冻结来源历史、工具结果和笔记为独立版本。由一个版本给多个接收端创建各自的计划，保留父计划和任务关联。 |
| M6 | 保存带接收方和后续要求的指派。允许离线领取，并发或重复领取同一指派复用同一目标。 |
| 开放接入 | CLI/MCP 运行时注册来源端、接收端或双向 agent。接入方实现本机会话协议即可参与按需拉取、离线领取及后续转交。 |

## 代码与数据的归属

| 部分 | 责任 |
|---|---|
| [接手协调器](../src/app.rs) 与 [指派](../src/assignment.rs) | 管理任务版本、计划和收件箱；校验 Git 工作树、保存 Markdown 笔记并发布目标。 |
| [客户端适配器](../src/agent.rs) | 发现会话、读取历史、创建目标原生记录并给出打开步骤。Codex 和 Claude 复用 txcript 的存储和消息转换。 |
| [DeepSeek 桥接](../adapters/deepseek.mjs) | 使用已安装的官方持久化 SDK 处理会话文件和事件；Rust 侧负责发起本地调用。 |
| [CLI](../src/main.rs) 与 [MCP](../src/mcp.rs) | 同一个可执行文件暴露两个入口，调用共同的应用逻辑。业务错误提供原因、类别、恢复操作和可重试性。 |

代码、暂存改动和未跟踪文件留在原 worktree。版本保存选定来源当时的历史和笔记；计划绑定版本、工作树和唯一目标。实时预览在发布前复核来源与笔记，独立版本按已冻结的内容交付。目标会话创建后，新进度由接收端按原生格式写入，可作为下一跳的来源。

准备和提交阶段的记录用于区分可回收的临时目录和提交结果不明的目录。恢复同库旧备份时，查询不会仅凭当前索引缺少一条计划而删除已经提交的计划文件。

## 后续扩展

协议客户端按[本机 Agent 接入协议 v1](agent-protocol.md)自助注册。私有格式的导入、窗口打开与工作目录恢复由客户端实现；中转站统一承担版本、指派和交付。

尚待扩展的范围包括向当前窗口注入上下文、接收端上线提醒、自动接手回执，以及更多会话格式与媒体类型。当前产品的操作说明和验证步骤见[中文 README](../README.zh-CN.md) 和[验收与复现](m0-m6-recheck.md)。
